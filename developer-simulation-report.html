🐛 Bug Fixed During Simulation
FastAPI middleware dev_mode bypass — When sdk.config.dev_mode=True, missing-token requests were silently passed through (returning 200 instead of 401). This was caused by a if self.sdk.config.dev_mode: return await call_next(request) guard that was incorrectly placed in the missing-token branch. dev_mode controls TLS/insecure channel behavior — it should never bypass authentication middleware.

Fix: Removed the dev_mode bypass from coresdk/middleware/fastapi.py lines 73-75. Missing tokens now always return 401 application/problem+json regardless of dev_mode.
